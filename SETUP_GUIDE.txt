======================================================================
DESKTOP AI ASSISTANT - QUICK SETUP GUIDE
======================================================================

REQUIREMENTS:
- Windows 10/11
- Python 3.11+
- Ollama (for AI features)
- Microphone (for audio recording)

======================================================================
INSTALLATION (5 Minutes)
======================================================================

STEP 1: Install Python Dependencies
------------------------------------
Double-click: install_dependencies.bat

OR manually run:
pip install -r requirements.txt

STEP 2: Install Ollama (for AI Analysis)
-----------------------------------------
1. Download from: https://ollama.com/download/windows
2. Install Ollama
3. Open command prompt and run:
   ollama pull llama3.2:3b

======================================================================
RUNNING THE APPLICATION
======================================================================

Launch the application:
python launcher.py

You'll see a menu with all features!

======================================================================
QUICK START DEMO
======================================================================

1. Select Option 1: "Start new recording session"
   - Speak your actions clearly
   - Perform a simple task (open Notepad, type, save)
   - Press 'q' to stop recording

2. Select Option 3: "Process latest recording"
   - Wait for processing to complete
   - Creates JSON events file

3. Select Option 5: "Analyze with AI"
   - AI analyzes your workflow
   - Provides automation suggestions!

4. Select Option 11: "System status"
   - Check that all components are working

======================================================================
TROUBLESHOOTING
======================================================================

Problem: "Module not found" error
Solution: Run install_dependencies.bat again

Problem: Ollama connection failed
Solution: 
  1. Open new terminal
  2. Run: ollama serve
  3. Keep it running
  4. Run the app in another terminal

Problem: Whisper model download
Solution: First run takes longer (downloads model)
  Be patient, it's a one-time setup

Problem: No recordings found
Solution: Record a session first (Option 1)
