🚀 Desktop AI Assistant - Quick Setup
=====================================
- Unzip DesktopAI-Assistant.zip.
- Double-click DesktopAI-Assistant.exe (Windows 10+ recommended).
- Menu Options:
  1-2: Record/view screen/audio sessions (saves to dashcam_outputs/).
  3-4: Process videos for patterns.
  5-6: AI insights (transcription, analysis).
  7-9: Build/execute automations (e.g., click-based workflows).
  10-11: Manage storage/status.
  12: Exit.
- First run: May take 30s to init AI components.
- Outputs: In app folders (data/, dashcam_outputs/).
- Req: Mic/webcam for recording; ~10GB free space for large videos.
- Issues? Run as admin or exclude from antivirus.
Enjoy automating! Questions → Reply.
